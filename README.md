# TROFEO Android Test v0.2

USB diagnostic build for Galaxy S25 Ultra + Thermalright Trofeo Vision 6.86" (VID 0416 / PID 5302).

## v0.2
- Automatic USB diagnostic on launch
- Lists every Android USB device with VID/PID, interface and endpoint details
- Shows USB Host support and permission state
- Explicit TROFEO FOUND / NOT FOUND result
- USB DIAGNOSTIC / REFRESH button
- Keeps v0.1 connect, handshake, test image and image-send functions
